## 1. はじめに

### インストール

1. `PicoSampler.vst3` を以下にコピーします。
   ```
   C:\Program Files\Common Files\VST3\
   ```
2. DAW でプラグインを再スキャンします。

### 最初の一歩

1. 波形エリアに WAV / AIFF / MP3 / FLAC / OGG を**ドラッグ&ドロップ**します。
2. 解析が終わると波形が表示され、Root Key が自動判定されます。
3. 鍵盤を弾けば鳴ります。

たったこれだけです。以降は音を追い込むための説明になります。

## 2. 画面の構成

上から順に、

| エリア | 内容 |
|---|---|
| **ヘッダー** | ロゴ / 読み込み中のファイル名 / Root Key / Key Range / AUTOSLICE / REANALYZE / PRESETS |
| **波形ディスプレイ** | 波形とマーカー。ドラッグで編集、ホイールでズーム |
| **キーレンジマップ** | 8スロットの鍵盤範囲。色付きバーをドラッグして変更 |
| **タブ** | MAIN / ARP・FILTER / MOD / FX / CONFIG |

### 波形ディスプレイの操作

| 操作 | 動作 |
|---|---|
| ドラッグ&ドロップ | サンプルを読み込む |
| マーカーをドラッグ | Start / End / Loop 位置を変更 |
| ホイール | ズーム（最大 100,000 倍） |
| 下端のバーをドラッグ | ズーム時のスクロール |
| 右クリック | ズーム中 → ズーム解除 / 等倍時 → サンプル削除の確認 |

### ノブの共通操作

| 操作 | 動作 |
|---|---|
| ドラッグ | 値を変更 |
| **Ctrl + ドラッグ** | **粗調整**（端から端まで一気に） |
| **Shift + ドラッグ** | **微調整**（サンプル単位の追い込み） |
| ダブルクリック | デフォルト値に戻す |
| 右クリック | 数値を直接入力 |

> 💡 Ctrl / Shift は**ノブを掴む前に押しておいてください**。掴んだ瞬間の状態で解像度が決まります。

## 3. MAIN タブ

### ACTIVE SLOT（S1〜S8）

編集対象のスロットを選びます。波形ディスプレイと下のノブ類はすべて、ここで選んだスロットの設定を表示します。

### PLAYBACK MODE

| モード | 動作 |
|---|---|
| **SINGLE** | 選択中のスロットだけ鳴る |
| **LAYER** | 鍵盤範囲が合致する全スロットが同時に鳴る（重ねて厚くする） |
| **RANDOM** | 合致するスロットから毎回ランダムに1つ選ぶ（人間味を出す） |

### ROUTING

**FLT BYPASS** / **FX BYPASS** はスロットごとに設定できます。ドラムのスロットだけドライのまま、パッドのスロットにはフィルターとFXをかける、といった使い分けが1つのインスタンス内で可能です。

### SAMPLE / LOOP

| ノブ | 説明 |
|---|---|
| **Start / End** | 再生範囲。連続値なのでいくらズームしても好きな位置に置けます |
| **L-Start / L-End** | ループ範囲 |
| **X-Fade** | ループのクロスフェード長（ループ長に対する比率） |
| **Pan** | スロットの定位。`L100` 〜 `C` 〜 `R100` |
| **Volume** | スロットの音量（-36 〜 +12 dB） |

| ボタン | 説明 |
|---|---|
| **LOOP** | ループ再生 |
| **STRETCH** | タイムストレッチ再生（ピッチを変えても速度が変わらない） |
| **REVERSE** | 逆再生。波形表示も左右反転します |
| **SNAP** | **オンにするとマーカーが必ずゼロ交差にスナップ**します |

> 💡 **SNAP について**
> オフのときはマーカーを完全に自由に動かせます。オンのときはカクカク動きますが、必ず波形がゼロを横切る点に着地するので、プチノイズが出ません。トランジェント（アタック）付近では吸着も働きます。

### ENVELOPE

Attack / Decay / Sustain / Release でスロットの音量変化を設定します。

**LINK** をオンにすると、現在のスロットの ADSR が**全8スロットに即座にコピー**され、以降ノブを動かすと全スロットが連動します。ドラムキットのリリースを一括で揃えたいときに便利です。

> ⚠️ LINK のオン/オフ状態はプリセットに保存されません（音は再現されます）。読み込み後に連動させたい場合は再度オンにしてください。

### PITCH

| ノブ | 説明 |
|---|---|
| **Root** | このサンプルの原音の高さ。`Auto` = 自動判定を使用 |
| **Octave** | ±3 オクターブ |
| **Semi** | ±24 半音 |
| **Fine** | ±100 セント |

### MASTER

全スロット共通の出力段です。Pitch（マスター移調）、HPF、LPF、Gain、Ceiling（リミッターの天井）。

## 4. ARP / FILTER タブ

### ARPEGGIATOR SETTINGS

**ARP ON** で有効になります。押さえた和音を自動的にアルペジオ再生します。

| 項目 | 説明 |
|---|---|
| **LATCH** | 鍵盤を離しても鳴り続ける |
| **SYNC** | オン = テンポ同期（1/1〜1/32）、オフ = Rate (Hz) で自走 |
| **パターン** | Up / Down / Up-Down / Down-Up / Up-Down (Incl) / Converge / Diverge / Pedal Low / Pedal High / As Played / Random / Random Walk / Chord の13種 |
| **Octaves** | 何オクターブ上まで駆け上がるか（1〜4） |
| **Gate** | 音の長さ（0.1〜1.0） |
| **Offset** | 全体を移調（±12半音） |
| **Swing** | ハネ具合（0〜75%） |
| **Repeat** | 同じ音を何回繰り返すか（1〜4） |
| **Accent** | 強弱の付け方（バイポーラ） |

### SCALE QUANTIZER

出てくる音を指定したスケールに強制的に収めます。**17スケール**（Free / Chromatic / Major / Natural Minor / Major・Minor Pentatonic / Dorian / Lydian / Mixolydian / Phrygian / Harmonic Minor / Melodic Minor / Whole Tone / Octaves & Fifths / Quartal / Sus2/4 Cloud / Diminished）。

Root Key は `Auto`（サンプルの判定結果を使用）または手動指定。

### MAIN FILTER

**3つのモデル**から選べます。

| モデル | 説明 |
|---|---|
| **Clean SVF** | 標準的なフィルター。LowPass / BandPass / HighPass / Notch、12 または 24 dB/oct |
| **Vowel Formant** | 母音（あ・い・う・え・お）のモーフィング。Formant ノブで移動 |
| **Comb Filter** | 金属的な響き。Comb Mix でウェット量を調整 |

**カーブ表示**はモジュレーションでリアルタイムに動きます。LFO を Cutoff に割り当てると、グラフが実際の音と同じように揺れます。

### FILTER ENVELOPE

フィルター専用の ADSR です。**Amt**（Amount）はバイポーラで、±4オクターブぶんカットオフを動かします。マイナスにすると閉じる方向のエンベロープになります。

## 5. MOD タブ

### SOURCES

**LFO タブ** — LFO 1〜4。波形は Sine / Triangle / Saw / Square / S&H / Chaos。SYNC オフなら 0.05〜30 Hz、オンならテンポ同期。

**ENV タブ** — ENV 1〜3。ADSR に加えて **Loop** スイッチがあり、オンにすると繰り返し動作する（LFO のような）エンベロープになります。

### MATRIX

16スロット（2ページ）あります。各行は

```
[ソース] → [行き先] [UNI] [Amount スライダー]
```

| 項目 | 説明 |
|---|---|
| **ソース** | LFO 1-4 / ENV 1-3 / Velocity / Note / Mod Wheel / Random の12種 |
| **行き先** | 全81種。スロット別の Start/End/Loop/X-Fade、S1〜S8 の Pan、Master Pitch、アルペジエイター全項目、フィルター全項目、FX の Amount と詳細パラメータ |
| **UNI** | オンで片側のみ（0→+）、オフで両側（−→+） |
| **Amount** | 変調量。ダブルクリックで 0 に戻ります |

> 💡 **変調量の見える化**
> 変調が掛かっているノブには、届く範囲が色帯で描かれ、現在値が明るい点で示されます。この表示は DSP と同じ計算式を通しているので、見た目と音が食い違いません。

> 💡 **Pan の行き先**は互換性維持のためリストの末尾（`S1/Pan`〜`S8/Pan`）にあります。

## 6. FX タブ

5つのスロットが**直列**につながっています。

- **カードのヘッダーをドラッグ**すると順番を入れ替えられます。
- **カードをクリック**すると、下の DETAILS エリアにそのFXの詳細パラメータが出ます。
- 各スロットの **AMOUNT** が全体のかかり具合です。

### FX の種類

| FX | パラメータ | 用途 |
|---|---|---|
| **Saturation (ADAA)** | ALGO（10種）/ DRIVE / PRE-HPF / TRIM | 歪み。エイリアスを抑えた方式 |
| **Ensemble Chorus** | RATE / DEPTH / WIDTH | 広がり・厚み |
| **Tape Delay** | TIME（同期）/ FEEDBACK / DUCK / DAMP | ディレイ。DUCK は入力時に自動的に引っ込む |
| **Freeze** | SIZE / FEEDBACK / DAMP | 音を引き伸ばして持続させる |
| **Shimmer Reverb** | DECAY / SHIMMER / DAMP / MOD | 残響。SHIMMER でオクターブ上がきらめく |

**Saturation の10アルゴリズム:** Soft Tanh / Hard Clip / Triode / Tape / Transformer / JFET / BJT / Wavefold / Exciter / Cubic

## 7. CONFIG タブ

| エリア | 項目 | 説明 |
|---|---|---|
| **ANALYSIS** | Material Mode | 解析の性格（Auto / Crisp / Smooth / Formant） |
| | Stretch Mode | ストレッチの性格（Beat / Tone / Texture / Complex） |
| **SLICING** | Slice Sens | オートスライスの細かさ。高いほど多く刻む |
| | Filter Slope | フィルターの標準スロープ |
| **SAMPLE EDGE** | Fade In / Fade Out | マーカー端のプチノイズ対策（0〜200 ms） |
| **PERFORMANCE** | Polyphony | 同時発音数（1〜32） |
| | Portamento / Glide Time | ポルタメント |
| **OUTPUT** | Lim Release | リミッターの復帰時間 |
| **APPEARANCE** | Color Theme | Midnight / Sakura / Ocean / Forest / Sunset / Mono |

> 💡 **Fade In / Out について**
> Start・End マーカーが波形の途中（振幅がゼロでない位置）にあると、再生開始・終了の瞬間に「プチッ」と鳴ります。この短いフェードがそれを消します。既定値の 2 ms / 3 ms は、聴感上は何も変わらずクリックだけが消える値です。`0` にすると従来どおりの完全なハードカットになります。
> ループ再生中は End 側のフェードは適用されません（ループのクロスフェードが担当するため）。

## 8. プリセット

ヘッダーの **PRESETS** ボタンで開きます。

### 保存

**SAVE** を押すと、サブカテゴリ名とプリセット名の入力画面が出ます。サブカテゴリは既存のものから選ぶことも、新しく打ち込むこともできます。

**保存される内容:**
全ノブ、全コンボボックス、全トグル、モジュレーションマトリックス（16スロット全部）、LFO・ENV 設定、FX の並び順と全パラメータ、8スロット分のサンプルファイルパス、Key Range、Root Key 設定。

> ⚠️ **サンプルの音声データ自体は保存されません**（パスのみ）。元のファイルを移動・削除すると、そのスロットは空の状態で読み込まれ、見つからなかったファイル名が一覧表示されます。

### 読み込み

プリセット名を**ダブルクリック**するか、選んで **Enter**。左のリストでカテゴリを絞り込み、上のボックスで検索できます。

### 削除

プリセット名を**右クリック** → `Delete...` → 確認ダイアログで **Yes**。

削除されるのはプリセットファイルだけで、参照していたサンプルには影響しません。ファイルはゴミ箱に移動されるので、誤操作しても戻せます。

### INIT

**すべてを初期状態に戻します。** 全8スロットのサンプルを消去し、全パラメータをデフォルト値に戻します。破壊的な操作なので確認ダイアログが出ます。取り消しはできません。

### 保存場所

```
C:\Users\<ユーザー名>\AppData\Roaming\PicoSampler\Presets\<カテゴリ>\<名前>.picopreset
```

エクスプローラーのアドレスバーに `%APPDATA%\PicoSampler` と入力すれば直接開けます。

## 9. すぐ使える設定例

### タイトなワンショットドラム

1. サンプルを読み込む
2. **SNAP** オン
3. Start をアタックの直前までドラッグ
4. CONFIG → Fade In `0 ms` / Fade Out `3 ms`

アタックはそのまま、リリース側のクリックだけが消えます。

### 継ぎ目のないループ

1. **LOOP** オン
2. **SNAP** オンのまま L-Start / L-End を配置
3. **X-Fade** を `0.1` 前後まで上げる

ゼロ交差に着地しているので段差が出ず、クロスフェードが繋ぎ目を埋めます。

### ブレイクビーツの切り刻み

1. ヘッダーの **AUTOSLICE** をオンにする
2. ループ素材を波形エリアにドロップ

トランジェントが検出され、最大8スライスが各スロットに展開されます。C1 から順に半音ずつマッピングされ、各スライスの終端は次のアタックの 1 ms 手前に置かれます。

### 短いサンプルからパッドを作る

1. **STRETCH** オン
2. CONFIG → Stretch Mode を `Tone` または `Complex`
3. **LOOP** オン、**X-Fade** を長めに

49本のアンカーバッファにより、4オクターブ移調してもフォルマントが崩れません。

### オートパン

MOD タブでソースに `LFO 1`、行き先に `S1/Pan` を選び、Amount を上げます。

### 動き続けるフィルター

1. MOD → ENV タブで `ENV 1` の **Loop** をオン
2. MATRIX で `ENV 1` → `Filter Cutoff`
3. ARP / FILTER タブでカーブ表示を見る

グラフが変調に合わせてリアルタイムに動きます。

## 10. 困ったときは

### 音が出ない

- **FILTER ON** になっていて Cutoff が下がりすぎていませんか
- スロットの **Key Range** が弾いている鍵盤を含んでいますか（キーレンジマップで確認）
- **PLAYBACK MODE** が SINGLE で、別のスロットが選ばれていませんか
- **Volume** が下がりきって `-inf` になっていませんか

### マーカーの位置でプチッと鳴る

- **SNAP** をオンにしてゼロ交差に合わせる
- CONFIG → **Fade In / Fade Out** を少し上げる（3〜5 ms）

### マーカーが思う位置に止まらない

- **SNAP** がオンだとゼロ交差にしか止まりません。自由に置きたい場合はオフにしてください

### ノブが細かすぎる / 粗すぎる

- **Ctrl + ドラッグ** で粗調整、**Shift + ドラッグ** で微調整
- 修飾キーはノブを掴む**前**に押してください

### プリセットを読んだらサンプルが無いと言われる

- 元のサンプルファイルが移動・削除されています。プリセットはパスを記録する方式のため、ファイルを元の場所に戻すか、読み込み直してから保存し直してください

### REANALYZE を押すと少し待たされる

- 49本のストレッチ用バッファを作り直しているためです。バックグラウンドで処理されるので、その間も操作は続けられます

### 音が途切れる・重い

- CONFIG → **Polyphony** を下げる（16 → 8 など）
- 使っていない FX スロットを `None` にする
